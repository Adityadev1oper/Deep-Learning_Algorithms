# Deep Learning Practice

A collection of deep learning implementations, notebooks, and mini-projects built while learning core DL concepts — from fundamentals to applied models.

## About

This repo is my hands-on practice space for deep learning as part of my journey toward becoming an AI/ML Engineer. It covers everything from neural network basics to more advanced architectures, implemented primarily in Python using PyTorch/TensorFlow.

## Topics Covered

- Neural Network fundamentals (perceptrons, forward/backward propagation)
- Activation functions, loss functions, and optimizers
- Building neural nets from scratch (NumPy) and with frameworks
- Convolutional Neural Networks (CNNs) for image tasks
- Recurrent Neural Networks (RNNs, LSTMs, GRUs) for sequence data
- Regularization techniques (Dropout, Batch Norm, Early Stopping)
- Transfer Learning
- Model evaluation and hyperparameter tuning
